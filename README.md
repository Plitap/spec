# PLITAP · Спецификация

Единое место для общей спецификации PLITAP и обсуждения её изменений.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Определения плитки, её состояния, истории и допустимых операций.
- Правила совместимости, сетевого взаимодействия и нативного профиля Pt.
- Каталог типов, предложения изменений, принятые решения и примеры.

## Границы направления

Нормативные правила относятся к этому репозиторию. Реализация проверок находится в [core](https://github.com/Plitap/core), а объяснения для пользователей — в [docs](https://github.com/Plitap/docs). Сейчас опубликована карта разделов; содержание ранее разработанной спецификации в эту публикацию не включено.

## Структура

| Раздел | Назначение |
|---|---|
| [`overview/`](overview/) | Назначение протокола, термины и порядок чтения будущей спецификации. |
| [`core/`](core/) | Общие инварианты цифровой плитки, полномочий и допустимых переходов. |
| [`tile/`](tile/) | Описание состава плитки, событий и переносимого представления. |
| [`network/`](network/) | Правила взаимодействия участников и проверки сетевого состояния. |
| [`profiles/`](profiles/) | Профили применения общих правил. Каждый профиль должен указывать собственную область действия. |
| [`profiles/plitap/`](profiles/plitap/) | Нативный профиль PLITAP и правила Pt. Тарифы и параметры выпуска здесь пока не опубликованы. |
| [`types/`](types/) | Каталог типов плиток, точных версий их определений и связанных обсуждений. |
| [`security/`](security/) | Нормативные требования безопасности; реализация и исследования находятся в соответствующих направлениях. |
| [`proposals/`](proposals/) | Предложения изменения правил с обоснованием, вариантами и статусом рассмотрения. |
| [`decisions/`](decisions/) | Принятые решения, причины выбора и ссылки на связанные предложения. |
| [`examples/`](examples/) | Примеры, привязанные к конкретной опубликованной версии правил. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Обсуждайте правила и типы в [Discussions](https://github.com/Plitap/spec/discussions). Конкретные правки и вопросы к тексту оформляйте в [Issues](https://github.com/Plitap/spec/issues) или pull request.

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
